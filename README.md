# QuoteHub

A small, easy-to-run project that scrapes quotes and their authors from the web using Beautiful Soup, stores them locally, and serves random quotes via a Flask web application. QuoteHub is ideal as a learning project for web scraping, data storage, and building a minimal Flask frontend that returns randomly chosen quotes.

## Features

- Scrapes quotes and authors from a target website using Beautiful Soup.
- Saves scraped quotes locally (JSON).
- Flask web app that:
  - Displays a random quote on a simple webpage.
- Easy to run locally, minimal configuration.

---

## Tech Stack

- Python 3.8+
- Beautiful Soup 4 (bs4) — HTML parsing and scraping
- Requests — HTTP requests for scraping
- Flask — lightweight web framework
